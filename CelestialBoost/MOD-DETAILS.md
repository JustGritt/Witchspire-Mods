# Celestial Boost

## Description

Tired of hunting forever for that one shiny familiar? This mod cranks up the spawn odds of the rare wild-familiar variants — Celestial, Shifty, and Legendary (3-star) — so the good ones actually show up.

Press F8 in normal gameplay to open the panel, then head to Cheats -> Celestial Boost to dial in each one to your liking. Tune everything live, no restart needed.

This only works in single-player or as the host.

## Config

You can change the hotkey by editing `CelestialBoost.as`:

1. Open the file and locate `ToggleMenuKey`:
```
const FKey ToggleMenuKey = EKeys::F8;
```
2. Change the value to any other key, e.g. to set the G hotkey -> `EKeys::G`

## Installation Instructions

1. Download and extract the archive
2. Navigate to your game folder and check if a "Mods" folder exists, if not create one at:
   `C:\Program Files (x86)\Steam\steamapps\common\Witchspire\Hercules\Script\Mods`
3. Copy/paste `CelestialBoost.as` into the "Mods" folder
4. Fully restart the game
